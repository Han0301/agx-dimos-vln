# 工作空间说明

| 路径 | 用途 |
|---|---|
| `sh/activate_vln.sh` | 启动环境脚本，内容不变，已集中到 sh/ |

| `docker/`、`.devcontainer/` | 容器构建和开发环境配置 |

## 根目录保留规则

根目录可见文件保留 README.md、pyproject.toml 和 uv.lock。
`AGENTS.md` 已按用户要求放到 `docs/AGENTS.md`，根目录 README 提供入口。它不再自动覆盖整个项目，后续维护时需显式阅读；构建文件保持工具约定位置。
隐藏的 Git、Docker 和编辑器配置保持原位。新增操作文档放 `docs/`，Shell 脚本放 `sh/`，Python 辅助脚本放 `scripts/`，旧备份放 `other/backups/`。

## 当前验证边界

目录整理保留机器人运行源码、启动脚本、模型和服务配置；A* 构建辅助代码集中在对应源码目录。未启动机器人。
运行指南和当前配置统一使用 `10.10.10.56` 推理服务地址；部署前仍需确认相关服务已启动。
当前工作空间不提供旧机器的 `.venv`。运行 `bash sh/start_venv.sh` 可创建项目本地 Python 3.12 环境，并安装与参考 `dimos` 环境一致的 `unitree + navdp` 依赖。完整机器人启动仍需在 Orin 现场验证。

## A* 扩展构建

根目录不再需要 `setup.py`。`pyproject.toml` 声明扩展源码、优化参数和构建命令；`dimos/navigation/replanning_a_star/build_ext.py` 在构建时定位 pybind11 头文件，并保留 macOS 通用二进制的 CPU 参数兼容处理。
正常导航直接加载编译好的扩展，不触发编译。安装或重新构建时需要 C++ 编译器，构建环境要求 setuptools >= 80.9。


## Go2 专用裁剪

按真实 Go2 + D455 + 远端 XNavDP 的用途，删除了其他机器人、机械臂、遥操作、独立重建、memory2、独立 ROS 2 可视化、端到端测试及仿真目录，共 13 个目录，并删除 `robot/unitree/mujoco_connection.py`。按用户要求未创建备份。
启动注册表使用项目原有 AST 生成器重新生成。现有 Go2、WebRTC、相机、建图、导航、智能体、空间记忆和网页代码保留。
当前副本不再提供被删除的功能；剩余历史示例及条件分支可能仍提及这些功能。仅做源码与注册表检查，完整 Orin 启动仍需现场验证。
