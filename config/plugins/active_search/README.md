# 主动找物工作流

实现归属 `dimos/vln_task/search/`，由 VLN Task 调用。`dimos.plugins.active_search` 只保留旧导入和配置检查入口的兼容转调，不再保存独立任务逻辑。配置路径与字段保持兼容。

`find_object` 先用 D455 当前帧执行 [Simple 目标检测](../vln_task/README.md)。VLM 返回候选框且深度有效时进入接近规划。未返回候选框时进入或继续换视角，`None` 和无法解析的回复都走此流程。

## 模式选择

| 入口或装配方式 | 未见目标时的搜索方式 |
| --- | --- |
| `bash sh/start_vln_motion.sh` | 默认开启记忆探索，先查询历史视角，无可用候选时选择前沿 |
| 未启用记忆探索的 Python motion 装配 | 按预定朝向原地扫视 |
| preview/bag | 等待外部输入提供新视角，不主动发布速度 |

默认实机入口通过 `DIMOS_VLN_EXPLORATION_MEMORY` 选择记忆分支；Shell 脚本默认开启，Python 装配按现有参数选择。记忆候选经地图净空检查后由 XNavDP 规划，到达后，上层调用 tracker 尝试对齐记录朝向，再停稳复检；无可用候选或记忆不可用时继续前沿探索。前沿选择、冷却和终止条件见 [VLN 操作说明](../../../doc/skills/vln-operations/SKILL.md#自由探索测试)。这些任务决策均由上层实现。

## 原地扫视

- 未启用记忆探索的 motion 装配以首帧为 0°，依次转至 60°、120°、180°、240° 和 300°。每次停止并取得更新的同步帧后做一次 DET。
- 转向由 tracker 控制。里程计和 RGB-D 必须新鲜，碰撞检查不通过时停止。预览和 bag 等待外部换视角。
- 扫完预定方向后报告搜索结果。定向靠近复检没有次数上限。候选丢失时继续尚未检测的朝向。任务超时和停止指令仍然生效。

## 命中后靠近

实机 motion 装配命中但深度无效时，优先沿 bbox 方向靠近。使用 RGB-D 局部栅格选取 0.30–0.60 m 的安全短目标，并校验 XNavDP 路径。跟踪最多约 2 秒后停车取新帧复检。深度仍无效时用最新 bbox 更新短目标。候选消失或未能开始有效的定向短步时，返回当前模式的记忆/前沿探索或剩余朝向扫视。等待停稳后的新观测超时，或输入、探索条件不可用时报告终态。网页 Stop 和任务取消都会停止当前运动；preview/bag 等待外部新视角恢复深度。

```bash
python -m dimos.vln_task.search --check
```
